# Shuffle Card — ไอเดียสำหรับทำภายหลัง

บันทึกวันที่ 2026-10-09 สถานะ: ไอเดียจากผู้ใช้ ยังไม่ implement

Shuffle Card เป็น feature แยกออกมา โดยเตรียม deck แยกตาม category ให้ผู้เล่นเลือก category และ level ก่อนเริ่มเล่น

## Flow ที่ต้องการ

1. ผู้เล่นเข้า Shuffle Card แล้วเลือก category และ level
2. ระบบแสดงกองไพ่พร้อม animation สับไพ่
3. เมื่อเอาเมาส์ hover บนกองไพ่ ให้ highlight ไพ่ที่เมาส์ชี้อยู่
4. คลิกไพ่เพื่อหยิบขึ้นมาและเปิดหน้าโจทย์
5. หน้าไพ่มีโจทย์หรือคำสั่งสั้น ๆ ด้านบน และรูปอธิบายโจทย์หนึ่งรูปอยู่ตรงกลางเป็นส่วนหลัก
6. มี icon เล็ก ๆ สำหรับตอบคำถาม เมื่อคลิกจะแสดง popover ข้างไพ่ให้กรอกคำตอบ
7. กด Check แล้วระบบแจ้งว่าคำตอบถูกหรือผิด
   - ถ้าถูก: แสดงคำอธิบายเพิ่มเติม
   - ถ้าผิด: แจ้งว่าผิด แต่ไม่มีคำอธิบายหรือการเปลี่ยนไพ่อัตโนมัติ อยู่ที่โจทย์เดิม
8. กด Skip เพื่อข้ามคำถาม แล้ววนกลับเข้าสู่ animation สับไพ่ใหม่

## รายละเอียดที่ค่อยตกลงตอนเริ่มทำ

- ทางเข้า feature และวิธีเตรียม/จัดการ deck หลังบ้าน
- รูปแบบการตรวจคำตอบ เช่น คำตอบที่ยอมรับได้ ตัวพิมพ์ใหญ่/เล็ก และช่องว่าง
- หลังตอบถูกและอ่านคำอธิบายแล้ว จะไปต่อด้วยปุ่มหรือวิธีใด
- ไพ่ที่ตอบแล้วหรือ Skip จะกลับเข้ากองหรือไม่ และการป้องกันการสุ่มซ้ำ
- วิธีเลือกไพ่บนมือถือซึ่งไม่มี mouse hover

บันทึกนี้เก็บแนวคิดและ interaction ที่คุยกันไว้ การออกแบบหน้าจอ โครงสร้างข้อมูล และ implementation จะทำเมื่อกลับมาพัฒนา feature นี้
