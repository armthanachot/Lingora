## ขอบเขตและความหมายของ “ครบพื้นฐาน”

ผู้เรียนเป้าหมายคือคนไทยวัยรุ่น/ผู้ใหญ่ที่เริ่มต้นหรือมีความรู้กระจัดกระจาย ไม่ต้องเริ่มท่อง A–Z แต่ยังต้องฝึกเสียง การอ่านคำ และการสะกดที่ใช้สื่อสารได้จริง

ขอบเขตคือฐานก่อน A1 ไปจนถึงแกน A1–A2 และโครงสร้างปลายพื้นฐานที่ช่วยต่อยอด คำว่า “ครบ” ในเอกสารนี้หมายถึงครอบคลุมหัวข้อและทักษะในขอบเขตที่ระบุ ไม่ใช่ grammar ทุกเรื่องของภาษาอังกฤษหรือรับรองว่าผู้เรียนทุกคนจะได้ระดับ A2 เพียงอ่านจบคอร์ส

CEFR ระบุระดับผ่านสิ่งที่ทำได้และใช้ข้ามภาษา จึงไม่ใช่รายการ grammar ภาษาอังกฤษสำเร็จรูป เราใช้ผลลัพธ์ A1–A2 เป็นเป้าหมาย แล้วตรวจรายการภาษาจากหลายแหล่ง ไม่อ้างว่าแหล่งใดรับรองการจัด modules ของ Lingora. [Council of Europe — CEFR levels](https://www.coe.int/en/web/common-european-framework-reference-languages/level-descriptions); [Council of Europe — A1/A2 global scale](https://www.coe.int/en/web/common-european-framework-reference-languages/table-1-cefr-3.3-common-reference-levels-global-scale)

รายการ Core Inventory เป็นแนวทางขั้นต่ำและการจัดระดับมีจุดทับซ้อน รายการสอบกับขอบเขตที่สอนให้ใช้คล่องก็ไม่เหมือนกัน จึงแบ่งความลึกเป็น: **ใช้ได้ด้วยตนเอง** สำหรับแกนหลัก และ **เข้าใจพร้อมสร้างตัวอย่างง่าย** สำหรับ clauses/passive/reporting ช่วงท้าย หัวข้อเหล่านี้อยู่ในเส้นทางทั้ง 4 คอร์สและไม่ถูกตัดหาย แต่ยังไม่ขยายทุกรูปขั้นสูง. [British Council–Eaquals — Core Inventory, 2011](https://www.eaquals.org/wp-content/uploads/EAQUALS_British_Council_Core_Curriculum_April2011.pdf); [Cambridge English — A2 Key Handbook, edition for exams from 2020, pp. 49–51](https://www.cambridgeenglish.org/images/504505-a2-key-handbook-2020.pdf)

ตารางและลำดับต่อไปนี้เป็นข้อเสนอทางการสอนของผู้จัดหลักสูตร โดยสังเคราะห์จากแหล่งที่อ่าน ไม่ใช่ syllabus ที่คัดลอกมาจากสถาบันใด การให้ชื่อ stage A–F เป็นกลุ่มช่วยอ่าน ไม่ใช่ระดับ CEFR ทางการ

## หลักจัดลำดับ

- เรียนหน้าที่ของคำและประธานก่อน subject–verb agreement
- รู้จักคำนามและการนับก่อน a/an/the; เรียนหลักนับเบื้องต้นใน M03 และขยายปริมาณใน M14
- แยก be กับกริยาทั่วไปก่อน do/does; แยก s ของคำนาม กริยา และความเป็นเจ้าของ
- ปูเสียงสั้น ๆ พร้อมฝึกต่อเนื่อง; เสียง s/es ฝึกเมื่อเรียน plural/verb s และ ed เมื่อเรียนอดีต
- เรียน frequency หลัง Present Simple และการบอกเวลา; How often กับ How long เป็นผลลัพธ์คนละอย่าง
- เรียน V2 กับอดีต; อธิบาย V3 ใน M20 แล้วฝึกใช้งานกับ Present Perfect และ Passive
- กริยาต่อกริยาและ clause เรียนเมื่อสร้างประโยคเดี่ยวได้แล้ว
- ฟัง พูด อ่าน เขียน และคำศัพท์แทรกตั้งแต่ M01; M32–M35 เป็นการรวมและขยายทักษะ ไม่ใช่การเริ่มฝึกครั้งแรก
- M01 เปิดฐานเสียงแล้วกลับมาฝึกควบคู่กับ modules ถัดไป ผู้เรียนไม่ต้องออกเสียงทุกเสียงสมบูรณ์ก่อนเริ่มสร้างประโยค
- วลีที่ยังไม่ปู grammar เต็มต้องระบุว่าเป็นวลีใช้งาน ไม่ใช้โครงสร้างนั้นเป็นสิ่งที่ต้องทำเองก่อนถึงบทที่สอน
- ทุก module ก่อน M36 มี checkpoint แบบผสมและการผลิตภาษาของตนเอง ไม่จบด้วยการเปิดอ่านเฉย ๆ

## ตาราง lesson ที่ต้องมี

รหัสก่อนจุดคือ module หลังจุดคือลำดับ lesson ภายใน module หัวข้อในช่อง “สิ่งที่ต้องสอนและฝึก” ต้องมีคำอธิบาย ตัวอย่าง การฝึก และ feedback ในเนื้อหาฉบับ implement ไม่ใช่เพียงแสดงชื่อคำศัพท์

“ควรรู้ก่อน” แสดง dependency ที่สำคัญ ผู้เริ่มต้นใช้ลำดับ M01 → M36 และนำความรู้จาก modules ก่อนหน้ามาใช้ร่วมกัน; ไม่ใช่กราฟสำหรับให้กระโดดเรียนโดยอัตโนมัติ

| ฟังและออกเสียง | ฟังความหมายและฝึกรูปเสียงเป้าหมาย | เสียงและ transcript; ฝึกเสียงท้าย/รูปย่อที่เกี่ยวข้อง |
| ใช้ภาษาของตนเอง | พูด/เขียนข้อความใหม่ในบริบทสั้น | prompt ที่ไม่ให้คัดลอกตัวอย่างตรง ๆ พร้อมตัวอย่างคำตอบที่ยอมรับได้ |
| ทบทวน | ดึงความรู้เดิมกลับมาใช้ร่วมกัน | โจทย์ผสมและการทบทวนใน modules ต่อไป |

การฟัง/พูด/อ่าน/เขียนแทรกตั้งแต่ต้นและปรับความยาวตามผู้เรียน รูปแบบกิจกรรมเป็นข้อกำหนดการสอนสำหรับขั้น implement ซึ่งต้องตรวจความสามารถ lesson blocks ก่อนผลิตจริง ยังไม่สมมติว่าระบบปัจจุบันตรวจเสียงพูดหรือเขียนปลายเปิดได้ครบ

## การประเมินและการจบคอร์ส

เกณฑ์ต่อไปนี้เป็นข้อเสนอของ Lingora เพื่อทดลองและปรับกับผู้เรียนจริง ไม่ใช่เกณฑ์สอบ CEFR ทางการ

| จุดประเมิน | สิ่งที่ตรวจ | หลักฐานที่ต้องเห็น |
|---|---|---|
| ก่อนเริ่ม | อ่านคำ ฟังเสียง และสร้างประโยคที่ทำได้อยู่แล้ว | แนะนำจุดเริ่ม/เสริม ไม่ตัดสินจากการท่อง A–Z |
| หลังแต่ละ module | ความหมาย รูป และการใช้ของหัวข้อหลัก | โจทย์ใหม่และงานใช้ภาษาหนึ่งงาน; feedback และการกลับไปฝึก |
| หลัง M07/M12/M18/M22/M27/M31 | ใช้หลายเรื่องร่วมกัน | แทรกโจทย์สะสมใน checkpoint ของ module นั้น ไม่เพิ่มหัวข้อใหม่เพื่อสอบ |
| M36 | รูปภาษา + listening + reading + speaking + writing | แยกผลตามทักษะและหัวข้อ; ข้อสอบใหม่ ไม่ใช้ชุดฝึกที่เห็นเฉลยแล้ว |
| หลังเสริม | ทำเรื่องที่ผิดซ้ำในบริบทใหม่ | ดูความคงทนและการใช้ใหม่ ไม่เฉลี่ยคะแนนสูงมาปิดช่องว่างหลัก |

เสนอใช้ 80% สำหรับข้อคำตอบชัดเจนเป็นจุดเริ่มของการทดลอง ส่วน speaking/writing ใช้ rubric แยกความสำเร็จของงาน ความเข้าใจได้ การเลือกคำ/โครงสร้าง และความเชื่อมโยง ผู้เรียนต้องสื่อสารสาระสำคัญได้; สำเนียงไม่ต้องเหมือนเจ้าของภาษา การอ่านครบหรือ viewed เป็นข้อมูลการเข้าเรียน ไม่ใช่หลักฐานความเข้าใจ

## มาตรฐานการเขียนเนื้อหาในขั้น implement

- คำศัพท์ grammar ใช้เป็นเครื่องมือช่วยเข้าใจ ไม่ให้ผู้เรียนท่องชื่อศัพท์เทคนิคเพื่อผ่าน
- ทุกตารางผันกริยา/สรรพนามมีตัวอย่างและเหตุผลที่เลือกใช้ ไม่ให้จำสูตรโดยไร้ความหมาย
- สอนตามเสียงและบริบท เช่น a/an ตามเสียง ไม่ใช่กฎดู A/E/I/O/U อย่างเดียว
- ไม่เหมารวมว่า adjective ทุกคำลงท้ายแบบเดียว, adverb ทุกคำเติม ly, tense เลือกจาก time word อย่างเดียว หรือ ing ทุกคำคือ continuous
- ปูรูปมาตรฐานให้มั่นคง แล้วระบุข้อยกเว้นที่พบบ่อยโดยไม่ท่วมผู้เรียนด้วยข้อยกเว้นขั้นสูง
- ใช้ตัวอย่างใหม่และเฉลยที่เขียนเอง; แหล่งอ้างอิงใช้ตรวจความถูกต้อง ไม่คัดลอกบทเรียน/แบบฝึกหัด
- สอนรูปแบบอังกฤษที่ใช้สื่อสารได้ ทั้งความต่าง British/American ที่จำเป็นอย่างมีคำอธิบาย และใช้รูปสะกดสม่ำเสมอในเนื้อหา
- ให้ภาพ/เสียง/ข้อความฝึกตรงกัน; หากภาพเป็นภาพบรรยากาศต้องไม่ออกโจทย์ที่สรุปข้อมูลจากภาพไม่ได้
- ความยาว lesson ปรับตามภาระความรู้; lesson ที่มีหลาย contrast สามารถแยกเพิ่มระหว่างผลิตได้โดยไม่ตัด coverage ที่อนุมัติ
- อ่านจบหนึ่งบทต้องตอบได้ว่า “ใช้เมื่อไร”, “ประกอบอย่างไร”, “ต่างจากรูปที่คล้ายกันอย่างไร” และผลิตตัวอย่างของตนเองได้ในระดับที่ตั้งไว้

## ขอบเขตที่เก็บไว้คอร์สต่อยอด

รายการนี้ระบุขอบเขตอย่างเปิดเผย ไม่ใช่ละหัวข้อเงียบ ๆ ช่วงท้ายของคอร์สนี้ปูรูปง่ายไว้ก่อน แล้วเรื่องต่อไปนี้ค่อยฝึกระบบเต็มในระดับถัดไป

| หัวข้อ | ฐานที่คอร์สนี้ปูให้ | รายละเอียดที่ยังไม่ขยายเต็ม |
|---|---|---|
| Tense/aspect ขั้นต่อไป | Simple/Continuous ปัจจุบันและอดีต; Present Perfect; รูปอนาคต | Past Perfect, Perfect Continuous, Future Continuous/Perfect และการเปรียบเทียบหลายเวลาเชิงลึก |
| เงื่อนไขสมมติ | Zero/First Conditional | Second/Third/Mixed, wish/if only แบบเป็นระบบ |
| การคาดคะเนด้วย modal | may/might/could และความหมายพื้นฐาน | must/can't เพื่อ deduction เชิงลึก; modal + have + V3 |
| ถ่ายทอดคำพูด | say/tell/think + clause; indirect question ง่าย | backshift, reported questions/commands และ reporting verbs หลาย pattern เต็มระบบ |
| Relative clauses | defining who/which/that; where ง่าย | non-defining รายละเอียด, whose/whom ทางการ, reduced relatives |
| Passive | Present/Past Simple | Passive ของ tense อื่น; get-passive/causative have/get something done |
| โครงสร้างการเน้น | ลำดับประโยคปกติและ stress | inversion, cleft sentences, question tags เต็มระบบ และรูปทางการซับซ้อน |
| คำศัพท์ระดับสูง | คำ A1/A2 และกลุ่มคำทั่วไป | idioms/ศัพท์วิชาชีพ/academic vocabulary และ phrasal verbs ปริมาณมาก |

การมีหัวข้อในชุด lesson ของสถาบันไม่เท่ากับต้องสอนทุกความหมาย/ทุกข้อยกเว้นในระดับเดียวกัน เช่น Present Perfect มีส่วน beginner และ intermediate แยกกัน ในคอร์สนี้ใช้ส่วนพื้นฐานตามขอบเขตที่ระบุ. [British Council — Present perfect, beginner section](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/present-perfect)

## ความสัมพันธ์กับคอร์สเดิม

เสนอเปลี่ยนชื่อคอร์สเดิมเป็น **ภาษาอังกฤษในชีวิตประจำวันสำหรับผู้เริ่มต้น — Everyday English for Beginners** ตามหัวข้อที่มีอยู่ แล้วใช้เป็นพื้นที่ฝึกสื่อสารเพิ่มเติม ผู้เรียนใช้วลีง่ายในคอร์สเดิมคู่กับพื้นฐานช่วงต้นได้ ไม่ต้องรอจบทั้ง 233 entries ก่อนเริ่มใช้ภาษา

English Foundations มีแกนเป็นความรู้และทักษะที่สร้างภาษาใหม่ได้ ส่วนคอร์สเดิมมีแกนเป็นหัวข้อชีวิตประจำวัน ทั้งสองเชื่อมกันด้วยความรู้ที่ต้องใช้ในบทนั้น ไม่จัดว่าทุก situation ต้องอยู่หลัง grammar ทุกเรื่อง

## สิ่งที่เสนอให้อนุมัติ

1. ขอบเขตหนึ่งคอร์สตั้งแต่เริ่มต้นจนถึงแกน A1–A2 พร้อมโครงสร้างปลายพื้นฐานแบบง่าย
2. Coverage ตามตาราง 36 modules / 198 lessons เนื้อหาและประเมินรวม + 35 checkpoints = 233 entries
3. รูปแบบการสอนที่มีเหตุผล ตัวอย่าง ฝึกตอบ ฟัง/พูด และผลิตภาษาของตนเอง
4. เกณฑ์การจบที่ต้องเห็นหลักฐานความเข้าใจและทักษะ
5. ชื่อ English Foundations และข้อเสนอชื่อใหม่ของคอร์สเดิม

อนุมัติแล้วจึงเริ่มผลิตเนื้อหาและ implement ข้อมูลจริง จำนวน lesson อาจเพิ่มเมื่อแยกหัวข้อที่หนักเกินหนึ่งบท โดยต้องรักษา coverage ที่อนุมัติไว้
